# FRAME — Reel reference board

Instagramで見つけた映像を「元投稿へのリンク」として整理し、自分の動画素材を細かく分析するためのローカルファーストなWebアプリです。

## 起動

このフォルダで次を実行し、表示されたURLを開きます。

```sh
python3 -m http.server 4173
```

その後 `http://127.0.0.1:4173` を開いてください。

## 設計上の境界

- Instagramの保存済み一覧はアカウント本人だけが閲覧できます。
- 他者の動画は複製せず、元投稿へのリンクとして扱います。
- 速度変更、フレーム送り、区間ループ等は、利用者が権利を持つローカル動画で使えます。
- リファレンス、分析メモ、タグはブラウザー内に保存されます。

## 主な機能

- スマホ：2行×2列相当の横スクロール表示
- Instagram公式埋め込みによるカード内再生
- カテゴリフィルター、検索、並び替え
- Web Share API / リンクコピー（ボード内容をURL内に含め、メモは共有しない）
- 0.25〜2倍速、±5秒、30fps想定の1フレーム送り
- ミリ秒表示のシーク、IN/OUT区間ループ、マーカー
- Hook / pacing / shot list / audio / タグによる制作分解
